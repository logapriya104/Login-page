# 🔐 React Login Page

A simple and responsive Login & Authentication UI built using React.  
This project includes Sign Up, Login, Forgot Password, and Reset Password pages with navigation and state management.

---

## 🚀 Live Demo

👉 https://logapriya104.github.io/Login-page/

---

## ✨ Features

- Login page
- Sign Up page
- Forgot Password page
- Reset Password functionality
- Welcome page after login
- Form validation
- Redux state management
- React Router navigation
- Responsive UI design

---

## 🛠️ Technologies Used

- React
- Redux
- React Router
- JavaScript
- HTML5
- CSS3

src

## ⚙️ Installation

Clone the repository:
git clone https://github.com/logapriya104/Login-page.git

Go to project folder:
cd Login-page

Install dependencies:
npm install

Run the project:
npm start
